## 需求描述
需求标题：酒店集团折扣报价取消验证报价时间是否在公开报价时间段内
具体描述：
1. 使用一个已过期协议基础日期的项目，通过酒店集团端进入集团折扣查看是否出现toast弹窗
2. 实现代码在tests/hotel_group的contract_management目录下，创建一个用例文件，名字取test_hotel_group_discount_price.py
3. 注意测试用例层和page形式写法，做到POM形式，元素方法和定位形式分明
   - page可以在hotel_group的contract_management目录下,创建对应的page类，名字：hotel_group_discount_price_page.py
4. 使用参数化的形式提取出来，因为里面的传入项目名可能会改变
   - 涉及到参数化的可以放到data/test_cases里面，仿照书写一个json文件

## 步骤描述
1. 首先到/home页
   - 前面的域名不变，但是后续的路径有一些变化，因为这是集团团的：https://testenv.fangcang.com/RFP/hotelGroup.html#/home
2. 点击-签约项目菜单，选择下拉菜单中的：签约项目-选项 
3. 然后在-签约项目的页面中，需要先选择Tab项：项目报价总览
4. 点击搜索栏目的项目栏-填入固定项目名：测试1010
5. 点击搜索按钮，精准匹配出现的首项
6. 接着在首项目的操作栏栏中，存在编辑按钮： 集团折扣 ，可能存在多个需要精准匹配首个
7. 点击集团折扣的按钮
8. 跳转进入折扣报价详情页中
9. 断言不会出现toast弹窗：项目签约时间已经结束


## 以下是我使用playwright工具录制的，你可以参考一下使用，避免自行定位不到可以考虑使用

def run(playwright: Playwright) -> None:
    browser = playwright.chromium.launch(headless=False)
    context = browser.new_context()
    page.get_by_text("签约项目").click()
    page.get_by_text("签约项目").nth(1).click()
    page.get_by_text("项目报价总览").click()
    page.locator("label").filter(has_text="项目").click()
    page.get_by_label("项目").fill("测试1010")
    page.locator(".ml-15 > div").first.click()
    page.locator(".c-scrollbar-thumb").click()
    page.locator(".c-scrollbar-thumb").click()
    page.get_by_text("集团折扣", exact=True).click()
    page.get_by_text("项目签约时间已经结束").click()
