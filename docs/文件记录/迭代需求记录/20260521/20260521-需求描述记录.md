

# === 1:报价详情增加“内部跟进备注”功能-展开功能 ===
## 需求描述
需求标题：报价详情“内部跟进备注”功能-显示不下的展开功能存在性
具体描述：
1. 使用一个存在指定存在备注信息的酒店项目，进去点击项目酒店，检测备注栏目中显示展开情况;
2. 实现代码在operate的rfp_management目录下，使用已有用例文件：rfp_detailPage_project.py，新构建一个用例方法
   - tests/operate/rfp_management/test_rfp_detailPage_project.py
3. 注意测试用例层和page形式写法，做到POM形式，元素方法和定位形式分明
    - page在：pages/operate/rfp_management/rfp_detailPage_project.py
4. 使用参数化的形式提取出来，因为里面的传入项目名可能会改变

## 步骤描述
1. 首先到/home页
2. 点击菜单:签约管理，选择下拉菜单中选项：签约
3. 然后在：签约的页面中，需要先选择：已启动的Tab项
4. 点击搜索栏目的：签约项目选项中，填入固定项目名：自动化测试项目-价格页签固定酒店项-勿修改任何价格变动
5. 点击搜索按钮，精准匹配出现的首项
6. 接着在首项目的操作栏中，存在编辑按钮：去签约，可能存在多个需要精准匹配首个
7. 在去签约地图模式下中，选择如中签的页签：已中签
8. 已中签的页签里面可能存在多个酒店，我们可以选择第一个就可以了，参考之前写的
9. 然后在地图的右侧会有酒店详情弹窗，需要点击详情按钮：查看报价详情按钮，会打开新的标签页
10. 查看备注项目中是否存在展开按钮
11. 存在点击展开后，查看是否存在收起按钮



## 以下是我使用playwright工具录制的，你可以参考一下使用，避免自行定位不到可以考虑使用

def run(playwright: Playwright) -> None:
    browser = playwright.chromium.launch(headless=False)
    context = browser.new_context()
    page.get_by_text("签约管理").click()
    page.get_by_text("签约", exact=True).click()
    page.locator("div").filter(has_text=re.compile(r"^已启动$")).first.click()
    page.locator("label").filter(has_text="签约项目").click()
    page.get_by_label("签约项目").fill("hy")
    page.locator(".ml-15 > div").first.click()
    page.get_by_text("去签约").click()
    page.get_by_text("已中签").click()
    page.get_by_text("深圳雅园风尚酒店 经济型 3.5100").click()
    with page.expect_popup() as page1_info:
        page.get_by_text("查看报价详情").click()
    page1 = page1_info.value
    page1.get_by_text("展开 ▼").click()
    page1.get_by_text("收起 ▲").click()
